# 1С Программирование — задания для курса

Репозиторий с практическими и лабораторными заданиями по дисциплине «1С Программирование».

## О курсе

Курс охватывает основы разработки в 1С:Предприятие: установку и настройку платформы, ER-моделирование и проектирование баз данных, ключевые объекты конфигурации (справочники, документы, регистры накопления, регистры сведений, перечисления), проведение и оптимизацию движений документов, систему компоновки данных (СКД) для построения отчётов, а также инструменты автоматизированного тестирования (менеджер тестирования и тестовый клиент).

Задания рассчитаны на начинающих специалистов и построены по принципу от простого к сложному: сначала базовые объекты конфигурации, затем логика их взаимодействия, отчётность и автоматизация.

## Структура репозитория
```
├── README.md
└── Продвинутый курс/
    └── kt1.md   — Учёт товаров на складе: справочники, документы, регистр накопления
```  
Новые задания добавляются отдельными .md-файлами внутри соответствующей директории курса (по мере роста курса могут появиться и другие директории — например, для базового уровня).

## Формат задания

Каждое задание оформлено единообразно:

- **Цель** — что студент должен научиться делать
- **Части задания** — пошаговая структура с ориентировочным временем на выполнение
- **Критерии оценки** — таблица с распределением баллов (по умолчанию из 10)
- **Задание со звёздочкой** — усложнённый вариант для сильных студентов (опционально)

## Как использовать

1. Клонировать репозиторий или скачать нужный `.md`-файл.
2. Открыть задание, выполнить шаги в 1С:Предприятие / Конфигураторе.
3. Сдать результат согласно критериям оценки, указанным в задании.
