# Задание: «Учёт товаров на складе» — базовые объекты конфигурации 1С

## Цель
Научиться создавать и связывать между собой три базовых типа объектов 1С: справочники, документы и регистр накопления, а также проверить движения документов через отчёт.

## Часть 1. Справочники 

Создать три справочника:

1. **Номенклатура**
   - Реквизиты: `Артикул` (строка, 10), `ЕдиницаИзмерения` (строка, 10), `Цена` (число, 15.2)

2. **Контрагенты**
   - Реквизиты: `ИНН` (строка, 12), `Телефон` (строка, 20), `Адрес` (строка, неограниченная)

3. **Склады**
   - Реквизиты: `Адрес` (строка), `ОтветственныйМенеджер` (строка)

**Задача студенту:** заполнить каждый справочник 3–5 элементами вручную через интерфейс 1С:Предприятие.

## Часть 2. Регистр накопления 

Создать регистр накопления **ОстаткиТоваров** вида **Остатки**:
- Измерения: `Склад` (Справочники.Склады), `Номенклатура` (Справочники.Номенклатура)
- Ресурсы: `Количество` (число, 15.3)


## Часть 3. Документы 

Создать документ с табличной частью:

1. **ПриходТовара**
   - Шапка: `Склад` (Справочники.Склады), `Контрагент` (Справочники.Контрагенты)
   - Табличная часть «Товары»: `Номенклатура`, `Количество`, `Цена`, `Сумма`
   - Провести документ так, чтобы при проведении формировалось движение **приход** по регистру ОстаткиТоваров


## Часть 4. Проверка (10 мин)

- Создать простую печатную форму отчёта (можно временно через универсальный отчёт по регистру накопления) и убедиться, что после проведения нескольких документов прихода/расхода остатки по складам считаются корректно.
- Провести документ расхода на количество, превышающее остаток — обсудить, почему 1С это не блокирует автоматически (контроль отрицательных остатков — отдельная тема, до которой они ещё не дошли).

## Критерии оценки (10 баллов)

| Критерий | Баллы |
|---|---|
| Справочники созданы с нужными реквизитами | 6 |
| Регистр накопления создан корректного вида, с правильными измерениями/ресурсами | 4 |
| Документы проводятся и формируют движения | 4 |
