## Задание 2: Проведение документа через запрос, регистр оборотов «Затраты» и отчёт по остаткам

Продолжение первого задания — используем те же справочники (Номенклатура, Контрагенты, Склады) и регистр ОстаткиТоваров.

### Цель
Освоить проведение документа через запрос (а не через цикл по табличной части), научиться создавать регистр оборотов и строить отчёт по остаткам на СКД.

### Часть 1. Переписать проведение документа через запрос (40 мин)

Взять документ **Покупка** из первого задания и переписать обработчик проведения:

- Вместо цикла `Для Каждого СтрокаТЧ Из ТабличнаяЧасть Цикл ... КонецЦикла` — выполнить запрос таблице документа `Продукт.Продукты` 
- В запросе объединить (сгруппировать) одинаковую номенклатуру функцией `СУММА()`, если в табличной части встречаются дублирующиеся строки — это ключевая причина, почему запрос предпочтительнее цикла: он не пишет лишние записи движения на каждую строку, а агрегирует их.
- Заполнить движения регистра через `Движения.Покупки.Записать()`, используя выборку результата запроса (`РезультатЗапроса.Выгрузить()` → цикл по таблице значений, либо `ВыборкаДетальныеЗаписи`).

### Часть 2. Регистр накопления оборотов «Затраты» (40 мин)

Создать регистр накопления **Затраты** вида **Обороты**:
- Измерения: `Контрагент`
- Ресурсы: `Количество` 

### Часть 3. Отчёт по остаткам через СКД (30 мин)

Создать отчёт **Остатки** на системе компоновки данных:
- Источник данных — виртуальная таблица регистра `ОстаткиТоваров.Остатки()`
- Поля: `Номенклатура`, `КоличествоОстаток`
- Группировка по складу, с ресурсом (итогом) по количеству
- Добавить отбор по складу как настраиваемый параметр отчёта (чтобы пользователь мог смотреть остатки по одному складу или по всем сразу)

**Проверка:** после проведения нескольких документов прихода/расхода запустить отчёт и убедиться, что остатки по складам совпадают с ожидаемыми.
